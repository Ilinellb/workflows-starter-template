<product_requirements>
The application, RSBC Workflow Pro, is a progressive web app (PWA) designed for internal business workflow management, primarily for a service-oriented environment like hospitality. It features a role-based access control system with three main roles, recently renamed to: OPS Manager (formerly Super Admin), Assistant Manager (formerly Manager), and Attendant (formerly Employee).

**Core Functionality Implemented:**
- **Authentication & User Management**: JWT-based login, user registration (defaulting to Attendant), and a profile page with editable demographic data.
- **Tab-Based Interface**: The UI is structured around tabs that are conditionally rendered based on user role. Managers and OPS Managers have access to all Attendant tabs in addition to their own.
- **Time & Attendance**: Simple punch-in/out functionality.
- **Room Management**: Real-time status tracking for a set of rooms (e.g., Open, Occupied, Needs Cleaning) with timers. The state is intended to be global for all users.
- **Scheduling**: Calendar-based views for personal and team schedules, with managers able to assign shifts.
- **Time-Off System**: A complete workflow for employees to request time off and for managers to approve or deny requests.
- **Messaging/Communication**: A real-time chat system with WebSockets, supporting direct messages, group chats, announcements, and file attachments.
- **Organization Chart**: A visual, editable hierarchy of all users organized by department (Business Operations, Daily Operations, Front Desk Operations).
- **System Administration**: A powerful panel for OPS Managers to customize the application's theme (colors, logo) and manage which tabs are enabled for different roles.
</product_requirements>
